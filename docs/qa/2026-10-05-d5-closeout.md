## 二、live 策略与实证

- **推理档位定稿**：`LLM_EXTRA_BODY={"thinking": {"type": "disabled"}}`（等价 `reasoning_effort=none`）；实测三组 `reasoning_tokens` 41/14/**None**，`disabled` 组 content 稳定非空。
- **`response_format` 仅 `json_object`**：DeepSeek 端点不支持 `json_schema` → 客户端**自适应降级**已于 live 实证（`structured_mode=json_object`）。
- **flaky 实证与修复**：早期 `deepseek-flash`（thinking enabled）+ `max_tokens` 小 → reasoning tokens 吃光致偶发 `TruncationError`（`-m live` 与 `pytest -q` 结论矛盾）；修复 = `disabled` 配置 + preflight content guard + `max_tokens` 提升。
- **卡片数固化 `>=5`**：本机 3 次 `run_requirement_agent` 均 `cards=5` → live 断言由 `>=1` 固化为 `>=5`（提交 `8372ea0`）。
